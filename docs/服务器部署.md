# 服务器部署

业务和AI分开运行，App仅连接HTTPS业务入口。AI端口8090、Java端口8089均绑定回环地址，公网仅开放HTTPS端口。以下域名、证书路径、账号和目录是待你替换的部署示例，不表示已在你的服务器部署。

## 资源与安装

建议有NVIDIA GPU的Linux服务器。无GPU可用CPU模式尝试，但不能保证短时响应；2GB内存机器不宜直接加载完整Seed-VC。Windows本机的RTX4060不代表云服务器具有GPU。

将源码上传到 `/opt/aivoice`。不要上传 `.runtime`、node_modules、录音、Token或Windows虚拟环境。部署端重新建立Python 3.11环境并安装依赖：

```bash
cd /opt/aivoice
python3.11 -m venv ai-service/.venv
ai-service/.venv/bin/python -m pip install torch==2.4.1 torchaudio==2.4.1 --index-url https://download.pytorch.org/whl/cu121
ai-service/.venv/bin/python -m pip install -c ai-service/constraints.txt -r ai-service/requirements.txt -r ai-service/requirements-model.txt
git clone https://github.com/Plachtaa/seed-vc.git ai-service/vendor/seed-vc
git -C ai-service/vendor/seed-vc checkout 51383efd921027683c89e5348211d93ff12ac2a8
cd backend
mvn clean package
```

CPU机器将PyTorch索引改为 `https://download.pytorch.org/whl/cpu`。服务器编译使用JDK17或更高，输出字节码目标Java17。

## 环境文件

创建仅服务账号可读的 `/opt/aivoice/server.env`，配置示例：

```dotenv
AIVOICE_API_TOKEN=你生成的长随机业务Token
AIVOICE_AI_TOKEN=另一个长随机内部Token
AIVOICE_DATA=/opt/aivoice/backend/data
AIVOICE_TMP=/opt/aivoice/backend/data/tmp
AIVOICE_AI_DATA=/opt/aivoice/ai-service/data
AIVOICE_AI_URL=http://127.0.0.1:8090
BIND_ADDRESS=127.0.0.1
SEED_VC_DIR=/opt/aivoice/ai-service/vendor/seed-vc
SEED_RUNTIME=/opt/aivoice/.runtime/seed
HF_HOME=/opt/aivoice/.runtime/huggingface
TORCH_HOME=/opt/aivoice/.runtime/torch
SEED_DEVICE=cuda
SEED_AUTO_DOWNLOAD=0
```

先临时设置 `SEED_AUTO_DOWNLOAD=1` 运行 `bootstrap_model.py` 完成官方权重下载和实际加载，再恢复0。以加载程序实际退出码和健康状态为准。不要仅下载源码就宣称已部署模型。

## systemd

`ai-service/deploy/aivoice-ai.service` 和 `backend/deploy/aivoice-backend.service` 提供模板。先创建非root服务账号并授权它访问项目的data与.runtime目录，修改模板账号与路径，再安装到 `/etc/systemd/system/`。AI只运行一个worker；业务只运行一个实例，目录锁会阻止同时写入同一持久化目录。

日志通过journalctl查看；默认不记录Token、音频内容和完整上传文件名。任务失败日志记录任务UUID及异常类型，App获取可理解的失败原因。

## Nginx HTTPS入口

`backend/deploy/nginx.conf.example` 是完整站点片段，填入实际域名与有效证书路径。先执行 `nginx -t`，通过后再reload。App填写 `https://你的实际域名`。

API Token仅通过HTTPS传输。业务内网HTTP仅用于回环代理。不要把内部AI服务的8090端口放行到公网。部署本任务不会改动已有生日站点或其他端口。

## 数据与维护

- 后端 `data/voices`：参考录音与元数据，手动删除。
- 后端 `data/tasks`：原声、参考副本、变声结果和JSON状态，默认30天。
- AI `data/`：请求临时文件，请求完成后清理。
- `.runtime`：模型和缓存；模型初始化下载完成后可离线使用。

只备份你需要保留的录音与配置，密钥单独保存。服务器重启后模型会重新加载，业务任务状态会恢复；被中断的推理标记失败并提供重试，不冒充自动完成。
