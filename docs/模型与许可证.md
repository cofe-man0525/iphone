# Seed-VC 模型适配、版本与许可核对

核对日期：2026-11-08。

## 固定源码与推理方式

- 官方仓库：[Plachtaa/seed-vc](https://github.com/Plachtaa/seed-vc)。官方页面显示仓库已于2025-11-21归档。
- 本次检出的固定提交：`51383efd921027683c89e5348211d93ff12ac2a8`。
- 使用该提交真实存在的 `inference.py::load_models(args)` 和 `inference.py::main(args)`。
- 适配器先调用官方加载函数，缓存返回模型元组，再让官方main复用加载结果。没有编造名为`convert_voice()`之类的官方接口，也没有复制改写推理网络。
- 使用V1零样本音色转换、`f0_condition=False`、`length_adjust=1.0`；默认30扩散步、CFG 0.7。路径、设备、参数可用环境变量修改。
- 模型适配位于 `ai-service/seed_adapter.py`，通过 `VoiceModel` 协议隔离，以便替换归档实现。

## 依赖选择

上游requirements同时写了nightly和固定torch版本，并包含GUI、实时处理和训练依赖。本工程不直接盲装整份文件。

- Python 3.11。
- PyTorch 2.4.1 + torchaudio 2.4.1，同一CUDA 12.1或CPU索引，禁止混装nightly。核验时2.4.0在本机触发fbgemm.dll WinError126，采用[官方2.4.1修复版本](https://github.com/pytorch/pytorch/releases/tag/v2.4.1)，没有从第三方DLL网站拼装运行库。
- NumPy 1.26.4，SciPy 1.13.1，librosa 0.10.2，Transformers 4.46.3。
- 其余推理依赖见 `requirements-model.txt`；FastAPI等业务依赖见 `requirements.txt`。
- 不安装Gradio、实时GUI、声卡驱动、训练工具或V2模型。V1当前调用链未引用的accelerate等依赖也不作为默认项。

安装后必须执行真实加载与转换，不能只根据pip退出码判断模型可用。下载失败、依赖缺失、显存不足都会使 `ready=false`；错误原样记录到测试说明，转换请求返回失败，不回退到变调。

## 运行配置

`SEED_VC_DIR`：官方源码；`SEED_RUNTIME`：私有运行目录；`HF_HOME/TORCH_HOME`：缓存。

`SEED_DEVICE=auto/cpu/cuda`；`SEED_AUTO_DOWNLOAD=1`：首次明确安装时允许下载，正常服务默认0离线加载；`SEED_DIFFUSION_STEPS=30`；`SEED_GUIDANCE_RATE=0.7`。

`SEED_CHECKPOINT`与`SEED_CONFIG`需同时设置为已核验的模型文件路径。默认使用上表官方V1模型。不要将未明来源的PyTorch pickle权重放入该目录。

此机器直接连接Hugging Face出现连接超时/SSL EOF，后续按上游README建议使用 `HF_ENDPOINT=https://hf-mirror.com` 下载。主权重、BigVGAN、Whisper的SHA256与官方文件页面核对；CAMPPlus来自固定官方Git提交，使用已记录哈希。固定模型快照与实际文件校验记录保存在 `.runtime/seed/asset-verification.json`。源码72个Python/YAML文件的指纹保存在 `ai-service/source-manifest.json`，加载时会检查一致性。

模型下载脚本支持 `SEED_NO_ENV_PROXY=1`，表示下载器不继承环境代理；不是关闭TLS证书验证。所有模型资产先核验，再交给PyTorch；加载过程随后使用离线缓存，避免未经检查地更新权重。

CPU模式可尝试，速度与具体硬件、录音时长、扩散步数有关，不承诺固定转换耗时。本机检测到RTX 4060 Laptop 8GB，不代表你的服务器也有GPU。

首次下载：在项目根目录执行 `./scripts/install-model.ps1 -Device cuda`。加载成功后再按 `Windows运行.md` 启动服务。真实推理的实际结果见 `测试记录.md`。
